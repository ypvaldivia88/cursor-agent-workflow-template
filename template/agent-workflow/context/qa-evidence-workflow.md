# QA evidence (before PR)

1. Reproduce on the branch that will ship.
2. Capture proof (screenshot, test output, API response summary).
3. Save under `.agent-workflow/temp/<issue-key-lower>/qa-screenshots/`.
4. List paths in chat; user embeds in PR or issue tracker manually if needed.

Do not skip when local/staging repro exists (`proj-no-pr-without-verification.mdc`).
